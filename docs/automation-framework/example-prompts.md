# Automation Framework example prompts

These prompts show how an AI agent can use `AGENTS.md` to extract useful information, identify business value and prepare structured presentation content.

## 1. Identify the business use cases

```text
Using only the information contained in AGENTS.md, identify the concrete Automation Framework business use cases.

For each use case, provide:

- Exact use-case name
- Business problem
- Solution
- Supporting tools or technology categories
- Confirmed outcomes
- Information requiring NTT DATA validation

Do not classify individual lifecycle stages, environments, tools or framework capabilities as separate business use cases.

Do not infer or invent missing information.
Do not access confidential local sources.
```

## 2. Extract the value proposition

```text
Using only AGENTS.md, explain the value proposition of the Automation Framework.

Organise the answer into:

1. Business problems addressed
2. Technical capabilities
3. Operational improvements
4. Governance, auditability and traceability benefits
5. Reusable elements across different use cases
6. Information requiring NTT DATA validation

Clearly distinguish confirmed information from implementation recommendations.

Do not invent quantitative results or customer-specific benefits.
Do not access confidential local sources.
```

## 3. Generate a CI/CD/CT Mermaid diagram

```text
Using only AGENTS.md, generate a Mermaid flowchart representing the Automation Framework CI/CD/CT lifecycle and its business value.

Requirements:

- Use a left-to-right flow.
- Represent this lifecycle:
  Validate → Build → Secure → Push → Deploy → Test → Mandatory gates decision
- From the mandatory-gates decision:
  - Yes → Promote → Next environment or Production
  - No → Promotion blocked
- Show quarantine when artefact-intake validation fails.
- Separate:
  1. Pipeline stages
  2. Automation and governance controls
  3. Business value
- Include Git as source of truth, artefact registry, CI controls, GitOps reconciliation, Continuous Testing and traceability evidence.
- Keep node text concise.
- Use <br/> for line breaks.
- Do not create connections that bypass mandatory gates.
- Return only valid Mermaid code.
- Mark uncertain relationships as Requires NTT DATA validation.
- Do not access confidential local sources.
```

## 4. Draft one PowerPoint slide

```text
Using only AGENTS.md, draft the content and visual structure for exactly one PowerPoint slide summarising the main Automation Framework business use cases.

For each selected use case, include:

- Business problem
- Solution
- Confirmed outcome

Also include:

- A short value-proposition message
- Supporting framework capabilities
- Information requiring NTT DATA validation

Follow the visual, terminology, confidentiality and uncertainty-classification rules defined in AGENTS.md.

Prioritise readability and one principal message.
Do not create a miniature complete presentation.
Do not access confidential local sources.
Do not create or modify files.
```

## 5. Compare extraction-tool outputs

```text
Compare the reviewed Markdown outputs generated by MarkItDown, Docling and MinerU.

For each tool, evaluate:

- Text completeness
- Reading order
- Title and section detection
- Table extraction
- Diagram and image handling
- Noise or duplicated content
- Suitability as input for a future PPT Maker application

Base the comparison only on the provided reviewed Markdown files.

Do not assume that one tool is always superior.
Clearly identify which observations come directly from the files.
```
